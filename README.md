# Бот для розыгрышей в Telegram-каналах

Админ канала создаёт розыгрыш в личке с ботом, бот публикует пост с кнопкой «Участвовать», проверяет подписку участников и в назначенное время честно выбирает победителей среди тех, кто всё ещё подписан.

Бесплатно: 1 активный розыгрыш, до 3 победителей, подпись бота под постом.
Премиум (Telegram Stars, подписка на 30 дней): до 20 розыгрышей, до 100 победителей, без подписи.

## Как запустить на своём компьютере

1. **Установите Python 3.11 или новее** с [python.org](https://www.python.org/downloads/). На Windows при установке поставьте галочку «Add Python to PATH».
2. **Создайте бота.** В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`). BotFather пришлёт токен вида `123456789:AA...`. Это пароль бота, никому его не показывайте.
3. **Скачайте эту папку** и откройте в ней терминал (на Windows: в адресной строке папки напишите `cmd` и нажмите Enter).
4. **Установите библиотеки:**
   ```
   python -m venv venv
   venv\Scripts\activate        (на Windows)
   source venv/bin/activate     (на Mac/Linux)
   pip install -r requirements.txt
   ```
5. **Вставьте токен.** Скопируйте файл `.env.example` под именем `.env` и замените в нём `123456789:ВАШ_ТОКЕН` на свой токен.
6. **Запустите:** `python bot.py`. Пока окно открыто, бот работает.

## Как проверить

1. Создайте свой тестовый канал и добавьте бота туда администратором (право «Публикация сообщений»).
2. Напишите боту `/new` и ответьте на вопросы. Время итогов поставьте поменьше, например `1` (час), или подведите итоги вручную через `/my`.
3. С другого аккаунта подпишитесь на канал и нажмите «Участвовать».

Чтобы проверить оплату, временно поставьте в `.env` цену `PREMIUM_PRICE_STARS=1` и купите подписку самому себе.

## Из чего состоит

| Файл | Что делает |
|---|---|
| `bot.py` | Запускает бота |
| `config.py` | Настройки и ограничения бесплатной/платной версии |
| `db.py` | База данных (файл `bot.db` создаётся сам) |
| `handlers/admin.py` | Создание розыгрыша и команда `/my` |
| `handlers/join.py` | Кнопка «Участвовать» |
| `handlers/premium.py` | Подписка через Telegram Stars |
| `draw.py` | Выбор победителей и проверка времени итогов |
